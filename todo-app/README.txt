오늘의 체크 — 사용 방법
====================

1. ZIP 파일을 압축 해제합니다.
2. 폴더 안의 index.html을 더블클릭합니다.
3. Chrome, Edge 등의 브라우저에서 할 일을 입력하세요.

주요 기능
- 할 일 추가, 완료 표시, 수정, 삭제(삭제 후 실행 취소)
- 업무·공부·개인 분류, 중요도, 마감일
- 모든 할 일 / 오늘 / 예정 / 완료 보기
- 분류별 필터와 검색
- 완료율 표시
- 브라우저에 자동 저장 (localStorage)

주의 사항
- 인터넷 연결 없이 실행됩니다.
- 같은 브라우저와 같은 환경에서 열었을 때 저장한 데이터가 유지됩니다.
- 브라우저 데이터 삭제, 시크릿 모드, 다른 컴퓨터에서는 목록이 이어지지
  않을 수 있습니다. 데이터는 서버로 전송되지 않습니다.
- CSS, JavaScript, 이미지 파일의 위치를 바꾸지 않아야 합니다.
